# Synergion — strona pokazowa

Wersja pokazowa nowej strony pracowni Synergion. Treści (projekty, opinie, liczby) są przykładowe.

- Strony: index.html, kontakt.html, projekty/*.html — generowane przez python build.py.
- Style: style.css, skrypty: main.js, font Manrope (OFL) lokalnie w assets/fonts.
- Zdjęcia w assets/img: Unsplash (licencja Unsplash), portrety zespołu i hero od Synergionu.
- Hosting: GitHub Pages, noindex do czasu akceptacji.
